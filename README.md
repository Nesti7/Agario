# 🐍 Змейка Агарио

Веб-игра "Змейка Агарио" - гибрид классической змейки и Agar.io с оптимизацией для слабых устройств.

## 🎮 Особенности

- **Плавный рост** - змея увеличивается сегментами при поедании еды
- **Управление мышкой** - змея следует за курсором
- **Большой мир** - игровое поле 5000x5000 пикселей
- **Оптимизация** - Spatial Hash Grid для быстрых коллизий
- **Адаптивность** - работает на ПК и мобильных устройствах

## 🚀 Запуск

### Локально

```bash
# Простой HTTP сервер (Python)
python3 -m http.server 8001

# Или с Node.js
npx http-server -p 8001
```

Откройте браузер: `http://localhost:8001`

## 🎯 Управление

- **ПК**: Мышка - змея движется к курсору
- **Мобильный**: Touch - змея движется к касанию

## 📋 Технологии

- Vanilla JavaScript (ES6)
- HTML5 Canvas 2D
- CSS3

## ⚡ Оптимизация

- **Spatial Hashing** - O(1) проверка коллизий
- **Viewport Culling** - рендер только видимых объектов
- **Object Pooling** - переиспользование объектов
- **FPS Limiting** - адаптивная частота кадров
